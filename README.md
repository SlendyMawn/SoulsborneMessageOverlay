# Soulsborne Message Overlay
### A program that allows you to display custom Soulsborne style messages on command.

This program built on [Godot Engine 4.7](https://godotengine.org/) acts as an overlay that sits over the top of your screen and can display custom soulsborne style 'noun-verbed' messages with accompanying sound and visual effects at any time.

This can be triggered via hotkey or via UDP packet from any local program. *(Stream Deck Plugin, Game/Tool Addons, etc)*
